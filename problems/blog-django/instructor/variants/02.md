# Carry the authenticated author through publication

The view verifies the identity header, discards the resulting author, and takes an author ID from the request body.
The form correctly omits that field, so the database rejects the creation attempt on its required foreign key.
Keep the author returned by `current_author(request)` and pass it into the serializer's save.
Then return the serialized resource under the public `post` key so the caller can recover its persisted ID.
Verify both API tests and check that the new entry appears under the signing user's My Posts.
